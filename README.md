# GTA WORLD

Browser-based mobile 3D open-world prototype.

## Third-party 3D assets

- City buildings, cars, taxi and trees: [Low Poly City Kit](https://github.com/kayquer/kit-cidade-lowpoly) by kkyqr, released under CC0 1.0.
- Player character: [Mini Characters](https://kenney.nl/assets/mini-characters) by Kenney, released under CC0 1.0. The GLB source mirror is [shorepine/kenney](https://github.com/shorepine/kenney).

These assets are used under their public-domain CC0 terms. They are loaded as GLB models by Three.js GLTFLoader. The game keeps procedural fallback geometry if a model cannot be downloaded.
